# Param Vaswani

I build instruments for sense-making, and write about what happens when you live inside them. The work runs under the **Center for Applied Post-Phenomenology** — [postphenom.com](https://postphenom.com).

Post-phenomenology asks what a technology does to perception. The Center makes that question practical: build the instrument, live inside it, write down what changed.

Everything here is local-first. No telemetry, no analytics, no third-party fonts or scripts. An instrument that reads your life reads it off your own disk.
